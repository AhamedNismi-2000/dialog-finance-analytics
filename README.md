# FinSight Lanka — Analytics Trainee Assessment

## 📊 Customer Data Analysis Project

This repository contains my end-to-end solution for the **FinSight Lanka Analytics Trainee Assessment**, including SQL analysis, Python data cleaning, Power BI dashboard development, KPI creation, and executive-level business insights.

---

## 🧠 Objective

To analyze customer financial behavior and deliver actionable insights across:
- Customer savings behavior
- Loan portfolio risk
- Digital engagement
- Product cross-selling opportunities

---

## 🛠️ Tools & Technologies

- SQL (Data extraction & analysis)
- Python (Data cleaning & preprocessing)
- Pandas
- Power BI (Dashboard development)
- DAX (KPI measures)
- Excel (Data validation)

---

## 📁 Project Files

- Q1_Savings_CustomerBehaviour.sql → Savings & customer analysis  
- Q2_LoanPortfolio_Risk.sql → Loan risk analysis  
- Q3_DigitalEngagement_ProductHoldings.sql → Digital usage analysis  
- Q4_KPIs.dax → KPI definitions used in Power BI  
- DataCleaning/ → Python scripts for data preprocessing  
- Dashboard/ → Power BI dashboard (.pbix file)  
- Q5_Q6_BoardSummary_SelfCritique.pdf → Executive summary & self critique  

---

## 📌 KPIs Developed

- Loan Default Rate %
- High Risk Exposure (Debt-to-Savings Ratio > 1)
- Cross-Sell Penetration Rate
- Mobile App Adoption Rate
- Average Savings per Customer

---

## 📊 Key Insights

- Premium customers contribute a disproportionately large share of total deposits
- More than half of loan customers show elevated financial risk exposure
- Significant cross-sell opportunity exists among savings-only customers
- Acquisition channels show different trade-offs between risk and value

---

## ⚠️ Limitations

- Dataset is static (no time-series analysis)
- No income or employment data available
- Some subgroup insights may be affected by small sample sizes
